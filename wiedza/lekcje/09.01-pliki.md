# Lekcja 9.1 — Pliki

## Cel
Po lekcji uczeń:
- Czyta cały plik przez `os.ReadFile` i zapisuje przez `os.WriteFile`
- Czyta plik linia po linii przez `bufio.Scanner`
- Zamyka pliki przez `defer` i rozumie, dlaczego to konieczne
- Obsługuje typowe błędy: brak pliku, brak uprawnień

## Krok 1 — Zakotwiczenie (5 min)
**Pytanie wejściowe:**
> "Program, który napisałeś do tej pory, po zakończeniu zapomina wszystko. Co musiałoby się stać, żeby lista zadań przetrwała do jutra?"

**Drugie pytanie:**
> "Masz książkę telefoniczną na 3000 stron i szukasz jednego numeru. Wnosisz całą książkę na biurko, czy otwierasz na właściwej stronie?"

→ przy małym pliku wszystko naraz jest wygodne; przy dużym trzeba czytać kawałkami.

## Krok 2 — Mostek (10 min)
**Mostek:**
> "Go daje oba sposoby. Mały plik: jedna linijka, wczytujesz całość. Duży plik: czytasz linia po linii, tym samym `Scanner`em, którego znasz z lekcji 2.4."

Uczeń tworzy `kurs/zadania/24-pliki/main.go`:

```go
package main

import (
	"fmt"
	"os"
)

func main() {
	tresc := "pierwsza linia\ndruga linia\ntrzecia linia\n"

	err := os.WriteFile("dane.txt", []byte(tresc), 0644)
	if err != nil {
		fmt.Println("nie mogę zapisać:", err)
		return
	}

	dane, err := os.ReadFile("dane.txt")
	if err != nil {
		fmt.Println("nie mogę odczytać:", err)
		return
	}

	fmt.Println(string(dane))
}
```

**Pytania:**
- "`[]byte(tresc)` — co to za konwersja?" → plik przechowuje bajty; tekst trzeba na nie zamienić. W drugą stronę: `string(dane)`.
- "`0644` — co to?" → uprawnienia pliku: właściciel czyta i pisze, reszta tylko czyta. Na Windows ignorowane.
- "Ile razy sprawdzamy błąd?" → po **każdej** operacji na pliku. Tu nie ma wyjątków od reguły z 6.1.
- Uczeń sprawdza w terminalu: `cat dane.txt` — plik naprawdę powstał.

## Krok 3 — Eksperyment (15-20 min)

1. **Plik, którego nie ma:**
   ```go
   _, err := os.ReadFile("nie-ma-mnie.txt")
   fmt.Println(err)
   fmt.Println(errors.Is(err, os.ErrNotExist))   // true
   ```
   > "Znasz `errors.Is` z 6.2. Do czego ci się przyda rozpoznanie właśnie tego błędu?"
   → np. "plik konfiguracji nie istnieje → użyj domyślnych ustawień" zamiast kończyć program
2. **Czytanie linia po linii:**
   ```go
   plik, err := os.Open("dane.txt")
   if err != nil {
       fmt.Println(err)
       return
   }
   defer plik.Close()

   skaner := bufio.NewScanner(plik)
   nr := 0
   for skaner.Scan() {
       nr++
       fmt.Printf("%d: %s\n", nr, skaner.Text())
   }
   if err := skaner.Err(); err != nil {
       fmt.Println("błąd czytania:", err)
   }
   ```
   > "Porównaj z lekcją 2.4. Co się zmieniło?" → tylko źródło: `plik` zamiast `os.Stdin`. To zasługa `io.Reader` z 8.2.
   > "Czemu `for skaner.Scan()` bez warunku porównania?" → `Scan()` zwraca `bool`: `true` dopóki są linie
   > "Co robi `skaner.Err()` na końcu?" → pętla kończy się i przy końcu pliku, i przy błędzie odczytu; to je rozróżnia
3. **`defer` w akcji** — uczeń usuwa `defer plik.Close()` i zastanawia się:
   > "Program działa tak samo. Więc po co zamykać?"
   → system operacyjny ma limit otwartych plików; program długo działający wyczerpie go i przestanie działać. Przy zapisie dochodzi drugi powód — punkt 4.
4. **Dopisywanie do pliku:**
   ```go
   plik, err := os.OpenFile("log.txt", os.O_APPEND|os.O_CREATE|os.O_WRONLY, 0644)
   if err != nil {
       fmt.Println(err)
       return
   }
   defer plik.Close()

   fmt.Fprintln(plik, "kolejny wpis")
   ```
   > "`fmt.Fprintln` do pliku — pamiętasz `io.Writer` z 8.2? Plik nim jest."
   > "Uruchom trzy razy i obejrzyj plik. Co robi `os.O_APPEND`?"
   > "A gdybyś użył `os.O_TRUNC` zamiast `O_APPEND`?" → plik byłby czyszczony przy każdym uruchomieniu
5. **Zapis z buforem** — wydajniej przy wielu liniach:
   ```go
   plik, _ := os.Create("duzy.txt")
   defer plik.Close()

   pisarz := bufio.NewWriter(plik)
   defer pisarz.Flush()          // WAŻNE — bez tego dane zostaną w buforze

   for i := range 1000 {
       fmt.Fprintf(pisarz, "linia %d\n", i)
   }
   ```
   > "Co się stanie, jeśli usuniesz `defer pisarz.Flush()`?" → niech spróbuje: plik będzie niepełny albo pusty
   > "Kolejność `defer`: który wykona się pierwszy?" → `Flush` (ostatni zadeklarowany), potem `Close`. Dokładnie taka jest potrzebna — z 5.3.

## Krok 4 — Pogłębienie (10 min)

**Co czym czytać:**
| Sytuacja | Narzędzie |
| --- | --- |
| Mały plik (konfiguracja, do kilku MB) | `os.ReadFile` |
| Duży plik, przetwarzanie linia po linii | `os.Open` + `bufio.Scanner` |
| Zapis całości naraz | `os.WriteFile` |
| Zapis stopniowy, wiele linii | `os.Create` + `bufio.Writer` + `Flush` |
| Dopisywanie do istniejącego | `os.OpenFile` z `O_APPEND` |

**Ścieżki:**
```go
import "path/filepath"

sciezka := filepath.Join("dane", "2026", "raport.txt")   // działa na każdym systemie
fmt.Println(filepath.Ext("raport.txt"))                   // .txt
fmt.Println(filepath.Base("/a/b/raport.txt"))             // raport.txt
```
> "Czemu nie sklejać ścieżek przez `+ \"/\" +`?" → bo na Windows separatorem jest `\`. `filepath.Join` wie, na czym działa.

**Sprawdzenie, czy plik istnieje:**
```go
if _, err := os.Stat("dane.txt"); errors.Is(err, os.ErrNotExist) {
	fmt.Println("nie ma pliku")
}
```
> "Uwaga: między sprawdzeniem a otwarciem plik może zniknąć. Zwykle lepiej **po prostu otworzyć** i obsłużyć błąd."

**Katalogi:**
```go
os.Mkdir("wyniki", 0755)
os.MkdirAll("a/b/c", 0755)     // z całą ścieżką
wpisy, _ := os.ReadDir(".")
for _, w := range wpisy {
	fmt.Println(w.Name(), w.IsDir())
}
```

**Usuwanie** — `os.Remove(nazwa)`. Ostrożnie: nie ma kosza, nie ma potwierdzenia.

## Pułapki
- **Zignorowany błąd zapisu** — `os.WriteFile` bez sprawdzenia `err` po cichu nie zapisze (pełny dysk, brak uprawnień, zła ścieżka).
- **Brak `Flush()` przy `bufio.Writer`** — dane zostają w buforze i nigdy nie trafiają na dysk. Klasyk.
- **Brak `defer plik.Close()`** — wyczerpanie limitu otwartych plików w programie długo działającym.
- **Ścieżki względne** — program czyta plik względem katalogu, z którego go **uruchomiono**, nie w którym leży kod. Częste źródło "przecież plik tam jest".
- **Sklejanie ścieżek ręcznie** — psuje się na Windows. `filepath.Join`.
- **`os.Create` na istniejącym pliku czyści go** — bez ostrzeżenia. Do dopisywania: `os.OpenFile` z `O_APPEND`.
- **Wczytanie wielkiego pliku przez `os.ReadFile`** — plik 4 GB trafia w całości do pamięci.
- **`ioutil.ReadFile`** — przestarzałe od 1.16. Jeśli uczeń zobaczy w tutorialu, ma używać `os.ReadFile`.

## Aktualizacja 2026 (z `AKTUALIZACJE.md`)
- **`os.ReadFile` / `os.WriteFile`** zamiast `ioutil.*` (od 1.16). Źródła sprzed 2021 używają starej nazwy.
- **`os.Root`** (1.24, rozszerzony w 1.25) — operacje ograniczone do jednego katalogu, bez możliwości wyjścia przez `../`:
  ```go
  root, err := os.OpenRoot("dane")
  plik, err := root.Open("raport.txt")   // "../tajne.txt" zostanie odrzucone
  ```
  Warto pokazać jako ciekawostkę bezpieczeństwa — przydatne, gdy nazwę pliku podaje użytkownik.
- **`strings.Lines(s)`** (1.24) — iteracja po liniach tekstu wczytanego w całości, bez ręcznego dzielenia.
