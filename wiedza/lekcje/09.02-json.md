# Lekcja 9.2 — JSON

## Cel
Po lekcji uczeń:
- Zamienia strukturę na JSON (`Marshal`) i z powrotem (`Unmarshal`)
- Steruje nazwami pól przez znaczniki `json:"..."`
- Zapisuje i wczytuje slice struktur z pliku
- Rozumie, dlaczego pola muszą zaczynać się wielką literą

## Krok 1 — Zakotwiczenie (5 min)
**Pytanie wejściowe:**
> "Zapisałeś w pliku tekstowym: `Anna,30,Kraków`. Jutro dopisujesz numer telefonu. Skąd program czytający ten plik wie, że czwarta wartość to telefon, a nie np. kod pocztowy?"

**Co chcesz usłyszeć:** nie wie — kolejność musi być umówiona i zapisana gdzieś obok.

**Drugie pytanie:**
> "A gdyby w pliku było napisane wprost: imię to Anna, wiek to 30? Co byś zyskał, a co stracił?"

→ zysk: dane opisują same siebie. Strata: plik jest większy.

## Krok 2 — Mostek (10 min)
**Mostek:**
> "JSON to właśnie taki format: dane wraz z nazwami. Cały świat go używa do wymiany informacji między programami. Go potrafi zamieniać struktury na JSON i z powrotem jedną linijką."

Uczeń tworzy `kurs/zadania/25-json/main.go`:

```go
package main

import (
	"encoding/json"
	"fmt"
)

type Osoba struct {
	Imie   string `json:"imie"`
	Wiek   int    `json:"wiek"`
	Miasto string `json:"miasto"`
}

func main() {
	a := Osoba{Imie: "Anna", Wiek: 30, Miasto: "Kraków"}

	dane, err := json.Marshal(a)
	if err != nil {
		fmt.Println("błąd:", err)
		return
	}
	fmt.Println(string(dane))

	ladnie, _ := json.MarshalIndent(a, "", "  ")
	fmt.Println(string(ladnie))
}
```

**Pytania:**
- "Co zwróciło `json.Marshal`?" → `[]byte` — dokładnie to, co przyjmuje `os.WriteFile` z 9.1
- "Znaczniki `json:\"imie\"` — porównaj wynik z nimi i bez nich" → bez nich pola wychodzą jako `Imie`, `Wiek` (wielką literą). Konwencja JSON to małe litery.
- "Czym różni się `MarshalIndent`?" → formatuje czytelnie dla człowieka

## Krok 3 — Eksperyment (15-20 min)

1. **Z powrotem na strukturę:**
   ```go
   tekst := `{"imie":"Piotr","wiek":25,"miasto":"Łódź"}`

   var p Osoba
   err := json.Unmarshal([]byte(tekst), &p)
   if err != nil {
       fmt.Println("błąd:", err)
       return
   }
   fmt.Printf("%+v\n", p)
   ```
   > "Czemu `&p`, a nie `p`?" → `Unmarshal` musi **zmienić** twoją zmienną. To wskaźniki z 7.2.
   > "Zapisz tekst w grawisach zamiast cudzysłowów — czemu?" → żeby nie uciekać cudzysłowów wewnątrz (z 2.3)
2. **Pole z małej litery** — najczęstsza pułapka:
   ```go
   type Zle struct {
       imie string `json:"imie"`   // mała litera!
       Wiek int    `json:"wiek"`
   }

   z := Zle{imie: "Anna", Wiek: 30}
   d, _ := json.Marshal(z)
   fmt.Println(string(d))   // {"wiek":30} — imie zniknęło!
   ```
   > "Gdzie się podziało `imie`? Wróć do lekcji 5.3."
   → biblioteka `encoding/json` jest w **innym pakiecie**, więc widzi tylko pola eksportowane (wielką literą). **Pola do JSON zawsze wielką literą.**
3. **Brakujące i nadmiarowe pola:**
   ```go
   var p Osoba
   json.Unmarshal([]byte(`{"imie":"Ewa"}`), &p)
   fmt.Printf("%+v\n", p)          // {Imie:Ewa Wiek:0 Miasto:}

   json.Unmarshal([]byte(`{"imie":"Ewa","kolor":"zielony"}`), &p)
   fmt.Printf("%+v\n", p)          // nadmiarowe pole zignorowane, bez błędu
   ```
   > "Brakujące pole daje wartość zerową (2.1), nadmiarowe jest ignorowane. Kiedy to wygodne, a kiedy niebezpieczne?"
   → wygodne przy zmieniających się formatach; niebezpieczne, gdy literówka w nazwie pola po cichu daje zero
4. **Slice struktur do pliku i z powrotem** — praktyczny cel lekcji:
   ```go
   ludzie := []Osoba{
       {Imie: "Anna", Wiek: 30, Miasto: "Kraków"},
       {Imie: "Piotr", Wiek: 25, Miasto: "Łódź"},
   }

   dane, err := json.MarshalIndent(ludzie, "", "  ")
   if err != nil { ... }
   if err := os.WriteFile("ludzie.json", dane, 0644); err != nil { ... }

   // odczyt
   wczytane, err := os.ReadFile("ludzie.json")
   if err != nil { ... }

   var znowu []Osoba
   if err := json.Unmarshal(wczytane, &znowu); err != nil { ... }
   fmt.Printf("%+v\n", znowu)
   ```
   Uczeń ogląda plik: `cat ludzie.json`.
   > "Masz trwałą bazę danych w 10 liniach. Co jeszcze byś do niej dołożył?"
5. **Znaczniki dodatkowe:**
   ```go
   type Produkt struct {
       Nazwa  string  `json:"nazwa"`
       Cena   float64 `json:"cena"`
       Opis   string  `json:"opis,omitempty"`   // pomiń, gdy pusty
       Sekret string  `json:"-"`                 // nigdy nie zapisuj
   }
   ```
   > "Uruchom z pustym `Opis` i zobacz różnicę. Do czego przyda się `-`?" → hasła, klucze, dane wewnętrzne
6. **Nieznana struktura danych** — uzasadnione użycie `any` z 8.2:
   ```go
   var cos map[string]any
   json.Unmarshal([]byte(`{"a":1,"b":"tekst","c":[1,2,3]}`), &cos)
   fmt.Println(cos["a"], cos["b"])

   if liczba, ok := cos["a"].(float64); ok {
       fmt.Println("liczba:", liczba)
   }
   ```
   > "Zwróć uwagę: `1` przyszło jako `float64`, nie `int`. JSON nie rozróżnia liczb całkowitych i zmiennoprzecinkowych."

## Krok 4 — Pogłębienie (10 min)

**Mapa typów JSON → Go:**
| JSON | Go (przy `any`) | Go (przy strukturze) |
| --- | --- | --- |
| `"tekst"` | `string` | `string` |
| `42` | `float64` | `int`, `float64` — jak zadeklarujesz |
| `true` | `bool` | `bool` |
| `[1,2]` | `[]any` | `[]int` |
| `{"a":1}` | `map[string]any` | struktura |
| `null` | `nil` | wartość zerowa |

**Odróżnianie "zera" od "braku"** — praktyczny problem:
```go
type Ustawienia struct {
	Limit *int `json:"limit"`   // wskaźnik!
}
```
> "Przy zwykłym `int` nie odróżnisz `\"limit\": 0` od braku pola — oba dadzą 0. Wskaźnik daje `nil` przy braku."
To jedno z niewielu miejsc, gdzie początkujący naprawdę potrzebuje wskaźnika poza metodami.

**Bezpośrednio z pliku, bez pośredniego `[]byte`:**
```go
plik, _ := os.Open("ludzie.json")
defer plik.Close()

var ludzie []Osoba
json.NewDecoder(plik).Decode(&ludzie)
```
> "`NewDecoder` przyjmuje `io.Reader` (8.2). Ta sama linia zadziała na odpowiedzi z sieci."

**Poprawność danych** — `Unmarshal` sprawdza **format**, nie **sens**:
```go
json.Unmarshal([]byte(`{"wiek":-5}`), &p)   // przejdzie bez błędu
```
> "Kto ma sprawdzić, że wiek nie może być ujemny?" → ty, po wczytaniu. To jest walidacja i wraca do modułu 6.

## Krok 5 — Ćwiczenie
→ Skill `cwiczenie`. Temat: "JSON". Sugerowane:
- 🔥 Struktura `Ksiazka` ze znacznikami, zapis jednego egzemplarza do pliku, odczyt i wypisanie
- ⭐ Lista kontaktów w JSON: wczytaj z pliku (przy braku pliku pusta lista), dodaj nowy wpis od użytkownika, zapisz
- ⚡ Wczytaj JSON o nieznanej strukturze do `map[string]any` i wypisz wszystkie klucze z typami (`%T`); posortuj klucze alfabetycznie (`maps.Keys` + `slices.Sorted` z 4.4)

Kod ucznia: `kurs/zadania/25-json/`.

## Pułapki
- **Pola z małej litery nie trafiają do JSON** — najczęstszy problem początkującego. Objaw: pusty albo niepełny wynik, zero błędów.
- **Brak `&` przy `Unmarshal`** → `json: Unmarshal(non-pointer)`. Kompilator tego nie złapie, błąd przychodzi w czasie wykonania.
- **Liczby z `any` są `float64`** — asercja na `int` panikuje.
- **Nadmiarowe pola ignorowane po cichu** — literówka w znaczniku (`json:"imei"`) daje wartość zerową i żadnego ostrzeżenia.
- **Zignorowany błąd `Unmarshal`** — przy uszkodzonym pliku struktura zostaje pusta i program liczy na zerach.
- **Znacznik ze spacją** — `json:"imie, omitempty"` (ze spacją po przecinku) nie działa. Bez spacji.
- **Cykl w danych** (struktura wskazująca na siebie) → `json: unsupported value: encountered a cycle`.

## Aktualizacja 2026 (z `AKTUALIZACJE.md`)
- Od **Go 1.27** `encoding/json` działa na silniku **v2**: szybszy i **surowszy** — odrzuca zduplikowane klucze i niepoprawny UTF-8. Kod ucznia się nie zmienia, ale plik, który kiedyś przechodził, dziś może zostać odrzucony. Przy dziwnym błędzie parsowania starego pliku: to może być przyczyna.
- `encoding/json/v2` był eksperymentem w 1.25 (`GOEXPERIMENT=jsonv2`), od 1.27 jest domyślną implementacją pod starym API.
- `os.ReadFile` (1.16) zamiast `ioutil.ReadFile` — dotyczy też przykładów z JSON-em w starszych materiałach.
